## 重启后怎么运行

机器人由固定支撑完全承重、两脚稍离地，关节周围无障碍，急停可立即切断电机动力。不要自动绕过保护恢复动力。

终端 1，先检查保存版本（不使能）：

```bash
python3 ~/BRUCE/imu_walk.py check
```

支撑就绪后启动站姿，保持这个终端打开：

```bash
python3 ~/BRUCE/imu_walk.py start
```

看到 `POSE_READY_PLACE_BOTH_FEET_ON_GROUND_NOW` 后，缓慢放稳双脚、扶正躯干，保留支架防倒和随行空间。终端 2 确认放地，才进入平衡控制：

```bash
python3 ~/BRUCE/imu_walk.py ground
python3 ~/BRUCE/imu_walk.py status
```

等状态为 `holding_balance` 且现场站稳、路线畅通，选择一条指令运行；不要同时运行多个控制程序：

```bash
python3 ~/BRUCE/imu_walk.py forward --seconds 12
python3 ~/BRUCE/imu_walk.py backward --seconds 12
```

两条是分别执行的前进／后退，不是必须顺序执行。可先 `--seconds 4` 短测；允许 0.5–12 秒。每次自动回站姿、恢复站立补偿并保持动力。行走时要为实际移动及收步留足空间。

停止整套控制前，先让支架完全承重，再在终端 1 按 Ctrl+C；保护停机后也先让支架承重。下一次启动前重新确认现场，勿自动重复运动命令。
