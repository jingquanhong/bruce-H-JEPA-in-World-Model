# 相机独立重现

在 Khadas 上运行。保持电机关闭；相机目前没有接入运动控制。

```bash
cd /home/khadas/BRUCE/diagnostics/orbbec-20261114
g++ -std=c++11 -O2 camera_probe.cpp \
  -I sdk/OrbbecSDK_v1.10.37/SDK/include \
  -L sdk/OrbbecSDK_v1.10.37/SDK/lib -lOrbbecSDK -pthread \
  -Wl,-rpath,/home/khadas/BRUCE/diagnostics/orbbec-20261114/sdk/OrbbecSDK_v1.10.37/SDK/lib \
  -o camera_probe

# 只枚举设备及可用模式：
./camera_probe

# 新建未使用的输出目录名称；每次约 8 秒，只保存选中的单组原始帧。
LD_LIBRARY_PATH=/home/khadas/BRUCE/diagnostics/orbbec-20261114/sdk/OrbbecSDK_v1.10.37/SDK/lib \
  taskset -c 0,1 ./camera_probe capture-next
OPENBLAS_NUM_THREADS=1 taskset -c 0,1 python3 process_capture.py capture-next
```

原始两组采集为 `capture-01`、`capture-02`。保留 RGB、深度原始帧、内参、深度比例、PNG 预览、PLY 点云、统计及采集日志。RGB 与深度没有做像素对齐；没有与机器人本体数据做时间同步；没有障碍检测、越障规划或模型训练。

SDK ZIP 是完整官方发行包。解压工具必须保留 Linux 符号链接；否则库目录中的链接会变成含链接目标文字的普通文件，无法正常加载。机器人上已经修正并成功加载，压缩归档保留真实链接。不要替换机器人现有 Python 或控制依赖。
